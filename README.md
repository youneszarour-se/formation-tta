# Formation Machine RFID Flip-Chip TTA

Parcours de formation vidéo (français / arabe) pour les nouveaux ingénieurs sur
la machine RFID Flip-Chip TTA.

La page est statique : elle lit `data.json` (étapes, sous-étapes, vidéos, points
clés) et lit les vidéos depuis Google Drive. L'avancement du stagiaire reste
dans son navigateur.

`data.json` est généré par le pipeline de production, à partir du guide de prise
en main et des enregistrements d'atelier. Ne pas éditer à la main.
